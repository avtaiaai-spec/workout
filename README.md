# Мои тренировки

Личное приложение для тренировок и замеров тела. React + TypeScript + Vite, IndexedDB и офлайн-PWA. Без обязательной регистрации и внешнего сервера данных.

## Запуск

Нужен Node.js 22+.

```sh
npm ci
npm run dev
```

Проверка собранного приложения и PWA:

```sh
npm run build
npm run preview
```

Service worker включён в production-сборке. В разработке Vite он не регистрируется. Для PWA нужен HTTPS или localhost.

## Новый пользовательский сценарий

1. При первом открытии список тренировок пуст. Нажмите «Новая тренировка», задайте название и выберите упражнения.
2. Для каждого упражнения один раз укажите **вес, количество подходов, повторения и отдых**. Для планки вместо веса и повторений — длительность в секундах. Для отведения ноги количество подходов задаётся **на каждую ногу**.
3. Нажмите «Сохранить тренировку». Изменения также автоматически сохраняются на устройстве.
4. На главной в блоке «В какие дни тренируемся?» выберите дни недели и назначьте свои тренировки. Один день может содержать несколько тренировок. Сохраните расписание с датой начала повторения.
5. В нужный день начните занятие. Появится независимая запись: можно отмечать подходы и исправлять фактический результат. Изменения занятия не меняют его исходный план.
6. После завершения результаты попадут в историю и статистику. Планы и невыполненные подходы не считаются выполненными.

Три ранее согласованные готовые тренировки можно добавить отдельно кнопкой **«Добавить мои три готовые тренировки»** в разделе «Тренировки». Они добавляются однократно и не перезаписывают пользовательские изменения. Новые готовые тренировки используют плие **с гирей**. При обновлении уже существующие тренировки и их прежние варианты не подменяются.

## Каталог: только 17 выбранных упражнений

1. Ягодичный мост в рычаговом тренажёре (hip thrust / glute drive).
2. Румынская становая тяга со штангой.
3. Отведение ноги назад в блоке.
4. Разгибание ног сидя в тренажёре.
5. Сведение ног сидя в тренажёре.
6. Приседания плие с гирей.
7. Румынская тяга с гантелями.
8. Гиперэкстензия с акцентом на ягодицы.
9. Сгибание ног лёжа в тренажёре.
10. Разведение ног сидя в тренажёре.
11. Планка на предплечьях.
12. Жим штанги лёжа на горизонтальной скамье в тренажёре Смита.
13. Жим в тренажёре от груди вперёд.
14. Горизонтальная тяга блока сидя узким хватом.
15. Вертикальная тяга широким прямым хватом к груди.
16. Разгибание рук в блоке.
17. Сгибание рук с гантелями.

У всех 17 упражнений новые реалистичные иллюстрации из двух положений, локальные WebP-файлы, описание техники, ошибки, история всех выполненных подходов и прогресс. Изображение можно открыть крупно. Старые изображения из линий и точек удалены. Поиск, категории, оборудование, избранное и выбор нескольких упражнений сохранены. Собственные пользовательские упражнения и изображения сохраняются.

Убраны из видимого встроенного каталога остальные упражнения. При обновлении они сохраняются в `retiredExercises`, а их снимки в тренировках и истории остаются целыми. В старой тренировке упражнение можно заменить вручную. **Плие с гантелью и плие с гирей имеют разные ID и не объединяют результаты.** Для сохранённого старого варианта без новой иллюстрации доступно текстовое описание, а не изображение другого упражнения.

Источники иллюстраций и лицензии: [MEDIA_LICENSES.md](MEDIA_LICENSES.md).

## Замеры тела

Раздел доступен через «Мои замеры» на главной, ссылку в «Прогрессе» и боковую навигацию на компьютере.

- Вес — кг; грудь, талия, бёдра, шея, левый/правый бицепс, бедро и голень — см.
- Дата и хотя бы одно положительное значение. Остальные поля необязательны. Ввод принимает точку и запятую.
- История всех записей, изменение и удаление с подтверждением, заметки.
- График выбранного показателя, таблица данных, изменение за период. На графике используется последний замер показателя за день; в истории остаются все записи.
- Период: всё время, 30/90 дней, год или свои даты.
- Отдельный CSV-экспорт и включение всех замеров в полную JSON-копию.

Показатели веса и обхватов не смешиваются с объёмом силовой нагрузки. Автоматические оценки «хорошо/плохо», калории и медицинские рекомендации не рассчитываются.

## Что сохранено

Светлая/тёмная/системная темы Calm Studio, локальный Golos Text, адаптивность, календарь месяца/недели, разовые даты, перенос и отмена одного занятия, будущие изменения недельных серий. Одно активное занятие, пауза, восстановление после перезагрузки, отдельные таймеры подхода и отдыха, ±15 с, произвольное время, звук/вибрация при поддержке браузером. Фактические результаты каждого подхода, комментарии, разминка, пропуск/замена упражнений, порядок, завершение частичного занятия, исправление истории и пересчёт статистики.

При составлении плана таблица каждого подхода больше не нужна: форма одна на упражнение. Если в сохранённой тренировке подходы раньше отличались, эти значения сохраняются; изменение одного поля распространяет только его на все подходы. Во время занятия фактический результат по-прежнему можно указать для каждого подхода отдельно.

Дробные веса 22,6 / 27,3 / 42,7 / 21,4 кг не округляются до шага тренажёра. В Смите учитывается добавленный вес **без грифа**. Для неуточнённого веса гантелей исходное число сохраняется и исключается из объёма до выбора способа учёта. Отведение ноги поддерживает отдельные отметки левой и правой стороны без повторного удвоения объёма. Планка в разных тренировках ссылается на одно упражнение.

## Хранение, обновление и перенос

Используется прежняя IndexedDB `moi-trenirovki`, объектное хранилище `state`. Формат данных — **версия 2**. Формат версии 1 автоматически читается и мигрирует без удаления тренировок, истории, активного занятия, таймеров, избранного и пользовательских изображений. Версия самой IndexedDB остаётся 1: новые данные находятся в том же объекте состояния, удалять или пересоздавать базу не нужно.

В настройках экспортируйте полную JSON-копию перед переносом или очисткой браузера. Она включает каталог, убранные упражнения, пользовательские изображения data URL, тренировки, расписание, исключения, все занятия, таймеры, настройки, тренировочные дни и замеры тела. Импорт принимает версии 1 и 2, проверяет структуру и дубли ID. Объединение сохраняет текущую запись при совпадении ID; полная замена требует подтверждения. Невалидный файл не меняет текущие данные. CSV-журнал подходов и CSV замеров не заменяют полную копию.

Данные хранятся на конкретном устройстве в конкретном браузере. Синхронизации между устройствами нет. Регулярно сохраняйте копию; браузер может очищать хранилище при нехватке места. Одновременная запись в нескольких вкладках не поддерживается.

Новая версия service worker ожидает закрытия старых окон приложения. Обновление не перезапускает активное занятие принудительно. После первой полной загрузки оболочка, шрифт и все 17 иллюстраций кэшируются для офлайн-работы.

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

Проверяются расчёты, точность готовых тренировок, настройка всего упражнения одной формой, миграция старого каталога и снимков истории, сохранение таймеров, недельное расписание, замеры и копии. Браузерный путь начинается с пустого списка тренировок, проходит через единый план упражнения и выбор дней на главной к фактическому занятию и восстановлению копии. Отдельно проверяется доступность всех 17 новых изображений офлайн и работа замеров.

В этой облачной среде есть `/usr/bin/chromium`. На другой машине:

```sh
npx playwright install chromium
CI=1 npm run test:e2e
```

Либо задайте `CHROMIUM_PATH`. Перед браузерными проверками выполните сборку. Скриншоты и trace сохраняются в игнорируемый `test-results/`.

## Публикация и установка на iPhone

В `.github/workflows/pages.yml` настроены проверки и GitHub Pages. После отправки изменений в `main`:

1. В GitHub выберите **Settings → Pages → Source: GitHub Actions**.
2. Дождитесь успешного workflow **Check and publish to GitHub Pages**.
3. Если первая публикация упала до включения Pages, включите его и нажмите **Re-run failed jobs**.
4. GitHub покажет фактический URL в Pages и в deployment workflow.

Для локальной проверки подпапки:

```sh
VITE_BASE_PATH=/workout/ npm run build
VITE_BASE_PATH=/workout/ npm run preview
```

Маршруты используют hash; manifest, шрифты, изображения и service worker учитывают подпапку. На iPhone откройте опубликованный HTTPS-сайт в Safari → «Поделиться» → «На экран Домой» → «Добавить».

Проверки телефона выполняются в Chromium на мобильном размере экрана. Физический iPhone/Safari не проверялся. Звук при заблокированном экране зависит от браузера и не гарантируется.
