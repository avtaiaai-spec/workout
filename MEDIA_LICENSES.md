# Изображения и лицензии

## Новые иллюстрации упражнений

17 иллюстраций созданы специально для приложения с помощью **OpenAI Image Generation** по отдельному описанию каждого упражнения. Это сгенерированные иллюстративные материалы. Каждая содержит два положения движения и соответствующий вид оборудования. Они не извлекались из пользовательских скриншотов, фитнес-приложений или сторонних каталогов.

Файлы находятся в `public/media/exercises/*.webp` и распространяются вместе с проектом по лицензии MIT (см. LICENSE). Исходные материалы созданы в рамках этой задачи; сторонние медиа-лицензии и платные API для их показа не требуются. Веб-приложение не обращается к генератору изображений: готовые файлы хранятся локально и кэшируются для работы без сети. WebP — оптимизированные копии исходных генераций.

Старый программно нарисованный медиакаталог полностью удалён из компонента `Illustration.tsx`. Для сохранённого старого упражнения без нового изображения показывается текст, а не иллюстрация другого варианта. Текстовая техника остаётся доступна при ошибке загрузки изображения. Пользовательские изображения сохраняются в JSON-копии в виде data URL; права на выбранные пользователем материалы определяются их источником.
