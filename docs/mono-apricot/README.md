# Mono Apricot

Скриншоты стартового раздела «План» после обновления навигации до трёх разделов. Используется отдельное тестовое состояние: три исходных шаблона, назначенное занятие и завершённое занятие. Пользовательские данные не используются и не заменяются этими записями.

| Размер    | Светлая                         | Тёмная                         |
| --------- | ------------------------------- | ------------------------------ |
| 390×844   | [Скриншот](light-390x844.png)   | [Скриншот](dark-390x844.png)   |
| 375×667   | [Скриншот](light-375x667.png)   | [Скриншот](dark-375x667.png)   |
| 1440×1050 | [Скриншот](light-1440x1050.png) | [Скриншот](dark-1440x1050.png) |

Проверено по текстовой спецификации: нейтральная основа, отдельный оранжевый/абрикосовый акцент, 28 px для заголовка, компактная неделя с кругом выбранной даты, открытый блок назначенного занятия, плоские раскрываемые строки шаблонов, минимальная навигация из трёх пунктов. В рабочем режиме занятия основная навигация отсутствует. Изображения упражнений сохранены.

При полном прогоне браузерных проверок также сохраняются снимки остальных экранов в `test-results/mono-*.png`. Проверяются границы элементов, отсутствие горизонтальной прокрутки, контраст текста от 4.5:1 и границ полей от 3:1, доступность управления, длинные названия и увеличение текста до 200%, сохранение темы и данных. На размере 390×844 основное действие и три строки шаблонов помещаются над навигацией; на 375×667 используется естественная прокрутка.

Проверки выполнены в Chromium. Экранная клавиатура проверена через изменение visual viewport; это не заменяет испытание на физическом iPhone/Safari. Отдельного изображения макета Mono Apricot в текущих вложениях нет, поэтому сравнение выполнено с указанными размерами, цветами и структурой, без заявления о совпадении пиксель в пиксель.
